iped-graph-neo4j — third-party notices

This package (the optional link analysis plugin of IPED) combines IPED code with the components below. The
package as a whole is distributed under the GNU GPL v3 (LICENSE.txt), because it includes Neo4j Community
Edition. IPED itself does not include any of these components: they are only present when this plugin is
installed in the IPED plugin folder.

Main components

Neo4j Community Edition 5.26.0
- Site: https://github.com/neo4j/neo4j
- License: GNU GPL v3 (LICENSE.txt)
- Usage: graph database engine (bulk import via neo4j-admin, post-import operations and the Bolt GraphServer),
  in iped-graph-neo4j/neo4j/; always run in child JVMs, never on the IPED classpath.

Neo4j Java Driver 5.26.0
- Site: https://github.com/neo4j/neo4j-java-driver
- License: Apache License, Version 2.0 (https://www.apache.org/licenses/LICENSE-2.0)
- Usage: Bolt client, embedded in iped-graph-neo4j-<version>.jar.

Netty 4.1.114 (netty-buffer, -codec, -common, -handler, -resolver, -transport, -transport-native-unix-common)
and netty-tcnative-classes 2.0.66
- Site: https://netty.io/
- License: Apache License, Version 2.0 (https://www.apache.org/licenses/LICENSE-2.0)
- Usage: network layer of the Neo4j driver, embedded in iped-graph-neo4j-<version>.jar and relocated under
  iped.graph.neo4j.shaded.io.netty.

Project Reactor reactor-core 3.6.10
- Site: https://github.com/reactor/reactor-core
- License: Apache License, Version 2.0 (https://www.apache.org/licenses/LICENSE-2.0)
