Neo4j Community Edition 5.26.0
- Site: https://github.com/neo4j/neo4j
- License: GNU GPL v3 (text in licenses/GPL 3.txt)
- Usage: graph database engine for IPED's link analysis (calls, e-mails,
  messages, wireless networks). The full embedded engine 5.26.0 (plus its
  Cypher/antlr 4.13 stack) is bundled isolated under lib/neo4j/ and run as a
  separate child JVM (GraphServer) speaking the Bolt protocol — this isolates
  Cypher's antlr 4.13 from the antlr 4.9.2 required by libfqlite on the main
  classpath. The processing/UI JVMs only carry the API jar (neo4j-graphdb-api)
  and the Bolt client (see below); they never load the full engine.
  Imports use neo4j-admin (org.neo4j.cli.AdminTool) from the same lib/neo4j/.
